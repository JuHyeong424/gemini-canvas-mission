# gemini-canvas-mission

Gemini Canvas 미션 결과물을 관리하는 저장소입니다.

## 목적

- Gemini Canvas로 제작한 웹앱 결과물을 기록하고 공유합니다.
- 앱별 요구사항, 배포 링크, 회고를 일관된 형식으로 남깁니다.

---

## 앱 이름: 우테코 데일리 회고
## 카테고리: 유틸리티 앱

### 배포 링크
https://gemini.google.com/share/b8357b7275dc

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?

  10개월간 우테코에 참여하는데 나중에 회고하기 위한 서비스가 필요했다. 우테코만을 위한 데일리 회고 앱을 만들어서 나중에 쉽게 볼 수 있도록 만들고 싶었다. 회고 작성에 익숙하지 않은 분을 위해서 간단하게라도 작성하게 만들면 어떨까 싶어 만들었다.

- 이 앱을 언제, 어떻게 사용할 건가요?

  우테코 정규 시간이 끝나고, 집이나 쉴 때, 퇴근 중에 휴대폰을 이용해서 간단히 작성할 수 있게 한다. 

### 주요 기능
- 하루 회고를 이모지, 오늘 한 일, 개선할 점을 두어 작성할 수 있도록 한다.
- 작성한 회고는 달력에 표시되어 해당 날짜를 클릭하면 회고를 볼 수 있도록 한다.
- 회고는 다음 날 오전 6시까지 작성할 수 있으며, 시간이 지난 회고는 수정할 수 없게 된다.

## 앱 이름: 미니 카트라이더
## 카테고리: 게임

### 배포 링크
https://gemini.google.com/share/60a57ebda1f8

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?

  쉬는 시간에 심심함을 달래줄 간단한 게임을 만들고자 했다. 레이싱 게임을 좋아해서 2D 카트라이더 게임을 만들었다. 

- 이 앱을 언제, 어떻게 사용할 건가요?

  공부를 하고 짧게 쉴 때, 동료와 내기를 할 때, 쉬고 싶을 때 사용한다.

### 주요 기능
- 방향키와 스페이스를 이용하여 다가오는 장애물을 피하면서 운전을 한다.
- 스페이스는 점프로 8초 쿨타임이 있고, 동물은 갑자기 다가온다.
- 경주가 끝나면 원하는 닉네임으로 기록을 남길 수 있다.

## 앱 이름: Frontend Daily Quiz
## 카테고리: 학습 앱

### 배포 링크
https://gemini.google.com/share/93cd08293eb3

### 이 앱을 만든 이유
- 어떤 문제/불편함을 해결하려고 했나요?
  
  웹을 만드는데에 집중을 하느라 웹에 대한 CS 지식이 부족할 때가 많다. 웹 개발자로 깊게 들어가려면 웹에 대한 지식은 필수라고 생각한다. 이를 해결하기 위해 웹에 대한 퀴즈를 만들었다. 

- 이 앱을 언제, 어떻게 사용할 건가요?

  웹 지식이 부족할 때, 하루에 한 번씩 시간이 날 때마다 문제를 푼다.

### 주요 기능
- 매일 추천 문제 5문제 (객관식 3문제, 주관식 2문제)를 풀고 해설을 확인한다.
- 공부하고자 하는 목차에 들어가서 5문제를 풀고 해설을 확인할 수 있다. 
- 모든 문제는 난이도를 선택해서 풀 수 있다. 

### AI 기능 (해당되는 경우)
- 어떤 AI 기능을 추가했나요?

  난이도에 맞는 5문제를 객관식, 주관식으로 제공해달라고 했다. 객관식 문제 선지는 서술형이어야 하고, 주관식 문제는 필수 단어 문제로 제출해달라고 요청했다. 

- AI 기능이 앱에서 어떤 역할을 하나요?

  난이도에 맞는 문제를 제공해주는 핵심 기능으로 작동한다.
